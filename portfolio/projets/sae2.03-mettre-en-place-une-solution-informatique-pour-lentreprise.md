# SAE2.03 Mettre en place une solution informatique pour l’entreprise

par [Kylian Adam](../)

## Contexte

Bientôt certains étudiants, comme moi, seront en alternance d'ici septembre 2024. Ces entreprises nous embauchent non seulement pour observer mais aussi pour travailler, pour produire à l'aide de ce que nous apprenons à l'IUT. Pour ce faire, cette activité nous donne un exemple de mission que nous pourrions recevoir dans une entreprise, elle nous donne l'occasion de devenir prestataire. Le client nous demande de créer une application web, avec plusieurs exigences à respecter. Mais parfois certaines exigences sont rajoutées alors que nous avons déjà commencé à travailler sur le projet, dans ce cas il faut garder une attitude professionnelle quant à notre décision.

## Consigne

Réaliser une application web de gestion de notes pour un système d'évaluation de notre formation en BUT (Des tables Groupes, Étudiants, Ressources, Unités d'enseignements, ...), basé sur une base de donnée déjà existante.

## My Task

So I took it upon myself to create the Gantt chart, a delivery that had to be made quickly. We collaborated on GitHub, I did the CSS part and above all the HTML, I had to add text tags to obtain elements stored in the database or fields to edit them. For faster and more efficient filling of table elements, we added a way to import a CSV file formatted for the application. This way, teachers can add the grades of all their students with a single click. I've written a user help document, which allows the user to use all the features of our application, such as the way the CSV file is structured.

## Ma réalisation

J'ai donc pris l'initiative de réaliser le diagramme de Gantt, c'était un livrable à rendre rapidement. Nous avons pu collaborer sur GitHub, j'ai réalisé la partie CSS et surtout HTML. J'ai dû ajouter du texte et des balises permettant d'obtenir des éléments stockés dans la base de donnée ou bien des champs permettant d'y écrire. Pour un remplissage plus rapide et efficace des éléments des tables, nous avons ajouté un moyen pour importer un fichier CSV formaté pour l'application. Ainsi les enseignants pourront ajouter les notes de tous leurs étudiants en un clic. J'ai écrit le document aide à l'utilisation, qui permet à l'utilisateur d'utiliser toutes les fonctionnalités de notre application incluant la manière dont est structuré le fichier CSV.
